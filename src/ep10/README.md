# الحلقة العاشرة: صفة الصلاة (ملفات التصميم)

ملفات بناء الحلقة، محفوظة لأي تعديل لاحق دون إعادة البناء من الصفر.

- `scene.html`: المشاهد كلها بدالة `render(T)`، ومعها `data.js` (توقيت كل كلمة من Whisper).
- `in/voice.mp3`: صوت حميد الأصلي، و`voice_edu.flac`: الصوت بعد إضافة الوقفات التعليمية (`prep.py`).
- `render.py`: تصدير الإطارات 1080×1920 بـ 30 إطارًا. `sfx.py`: المؤثرات الخافتة.
- الدمج: الصوت مؤخر ثانية واحدة (الغلاف)، ثم loudnorm حتى -14 LUFS.
- لتغيير «الحلقة القادمة» في بطاقة الختام: عدّل دالة `drawCard` ثم صدّر الثواني الأخيرة فقط.
